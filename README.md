# FIFO Depo Yönetimi — Kurulum Rehberi

## 📱 Netlify ile Ücretsiz Yayına Alma (Tıklayarak)

### Adım 1 — GitHub'a Yükle
1. https://github.com adresine git → Üye ol (ücretsiz)
2. Sağ üstte "+" → "New repository" 
3. İsim: `fifo-depo` → "Create repository"
4. "uploading an existing file" linkine tıkla
5. Bu klasördeki TÜM dosyaları sürükle bırak
6. "Commit changes" butonuna bas

### Adım 2 — Netlify'a Bağla
1. https://netlify.com adresine git → "Sign up with GitHub"
2. "Add new site" → "Import an existing project"
3. GitHub'ı seç → `fifo-depo` reposunu seç
4. Build ayarları otomatik gelir (netlify.toml sayesinde)
5. "Deploy site" butonuna bas → 2 dakika bekle ✅

### Adım 3 — Telefona Ekle (PWA)
**iPhone:**
1. Safari'de sitenin adresini aç
2. Alt menüde "Paylaş" (kare+ok ikonu) → "Ana Ekrana Ekle"
3. "Ekle" → Uygulama ikonunu görürsün ✅

**Android:**
1. Chrome'da sitenin adresini aç
2. Üstte "Ana ekrana ekle" bildirimi çıkar → "Yükle"
3. Veya: Sağ üst menü → "Uygulamayı yükle" ✅

**PC/Mac:**
1. Chrome veya Edge'de sitenin adresini aç
2. Adres çubuğunun sağında bilgisayar ikonu çıkar → tıkla → "Yükle"
3. Masaüstünde uygulama kısayolu oluşur ✅
